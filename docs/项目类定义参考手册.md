## 1. 数据库枚举 (Prisma Enums)

所有枚举定义在 `apps/api/prisma/schema.prisma`。

### CustomerStage — 客户开发阶段

| 值 | 含义 |
|---|---|
| `PENDING_RESEARCH` | 待背调 — 客户刚录入，尚未开始背调 |
| `RESEARCHING` | 背调中 — 正在执行AI背调 |
| `RESEARCHED` | 已背调 — 背调完成 |
| `PENDING_EMAIL_GENERATION` | 待生成邮件 — OEM评分≥60，等待生成开发邮件 |
| `PENDING_EMAIL_SEND` | 待发送邮件 — 邮件草稿已生成，等待审核后发送 |
| `FIRST_EMAIL_SENT` | 已发送首封邮件 — 首封开发邮件已发出 |
| `PENDING_SECOND_FOLLOW_UP` | 待二次跟进 — 首封后创建了二次跟进任务 |
| `REPLIED` | 客户已回复 — 收到客户回复 |
| `REQUIREMENT_CONFIRMING` | 需求确认中 — 客户回复后确认采购需求 |
| `QUOTING` | 报价中 — 已向客户发送报价 |
| `SAMPLING` | 样品中 — 已向客户寄送样品 |
| `NEGOTIATING` | 订单谈判 — 样品通过，进入正式价格/合同谈判 |
| `WON` | 已成交 — 赢单 |
| `PAUSED` | 暂缓开发 — 客户暂时搁置 |
| `INVALID` | 无效客户 — 无法转化 |
| `BLACKLISTED` | 黑名单 — 被拉黑 |

| 值 | 含义 |
|---|---|
| `DRAFT` | 新建 |
| `PENDING_APPROVAL` | 提交审批 |
| `APPROVED` | 审批通过 |
| `REJECTED` | 审批驳回 |

### QuoteStatus — 报价状态

| 值 | 含义 |
|---|---|
| `DRAFT` | 草稿 |
| `SENT` | 已发送 |
| `ACCEPTED` | 客户接受 |
| `REJECTED` | 旧版客户拒绝状态（仅兼容历史数据） |
| `CUSTOMER_REJECTED` | 客户拒绝 |
| `EXPIRED` | 到期失效 |
| `VOIDED` | 作废关闭 |

说明：客户拒绝统一使用 `QuoteStatus.CUSTOMER_REJECTED`，它是单个报价版本的终态，不允许直接修改；后续议价通过创建新修订版回到 `DRAFT`。审批驳回使用 `QuoteApprovalStatus.REJECTED`。

### Customer — 客户（核心实体）

`schema.prisma:319`

| 字段 | 类型 | 作用 |
|---|---|---|
| `id` | String (CUID) | 主键 |
| `organizationId` | String | 所属组织 ID |
| `sourceId` | String? | 客户来源 ID |

| `name` | String | 客户公司名称 |
| `normalizedName` | String | 标准化名称（小写去空格，用于去重） |
| `websiteUrl` | String? | 官网 URL |
| `websiteDomain` | String? | 官网域名（提取后用于去重） |
| `country` | String? | 国家/地区 |
| `language` | String? | 语言 |
| `timezone` | String? | 时区 |
| `currency` | String? | 货币 |
| `stage` | CustomerStage | 开发阶段（默认 PENDING_RESEARCH） |
| `riskLevel` | RiskLevel | 风险等级（默认 LOW） |
| `tags` | String[] | 标签数组 |
| `notes` | String? | 备注 |
| `createdAt` | DateTime | 创建时间 |
| `updatedAt` | DateTime | 更新时间 |

索引：
- `@@unique([organizationId, normalizedName])` — 同组织内不重名
- `@@index([organizationId, ownerId])` — 按负责人查询
- `@@index([organizationId, stage])` — 按阶段统计
- `@@index([websiteDomain])` — 按域名查重
